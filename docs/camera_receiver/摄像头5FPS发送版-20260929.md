# 摄像头 5FPS 发送版

日期：2026-09-29
程序：`bin/peerconnection_camera_5fps`
SHA256：`dd77ef8680815f3a299b425bcf02a7c7dd5add3794195b0533c6375a4f3a6e56`

## 1. 修改目标

旧摄像头路径内部固定为：

```text
640x480 @ 30 fps
```

因此命令行中的：

```text
--fps 5
```

之前没有真正限制发送帧率。

本版本增加了：

1. 将 `--width`、`--fps` 传入摄像头采集源；
2. 对摄像头回调做应用层帧率限制；
3. 只将满足 5fps 时间间隔的帧送入编码器和 WebRTC；
4. 保留 Stride 花屏修复。

底层 USB 摄像头驱动仍可能以约 30Hz 回调，但 Sender 的编码和网络发送已经按目标帧率抽帧。

## 2. Sender 命令

```bash
/home/cjq/Workspace/Pandia/bin/peerconnection_camera_5fps \
  --server 172.20.10.2 \
  --port 9999 \
  --width 640 \
  --fps 5 \
  --path camera \
  2>&1 | tee /home/cjq/camtest/sender_5fps.log
```

预期日志：

```text
Camera capture request: 640x480 @ 5 fps
```

判断实际发送帧率时，应看：

```text
Finish encoding
```

而不是底层的：

```text
Capture incoming
FrameCaptured
```

后两者可能仍显示摄像头驱动的原始回调频率。

## 3. 本机回归结果

测试时间约 7 秒：

| 项目 | 结果 |
| --- | ---: |
| 请求参数 | 640x480 @ 5 fps |
| 摄像头回调帧 | 226 |
| `Finish encoding` | 30 |
| Receiver `Frame received` | 29 |
| Receiver `Notify frame decoded` | 29 |
| 输出 YUV 文件 | 29 |
| 编码帧间隔 | 约 200 ms |
| 估算发送帧率 | 约 5 fps |
| 丢包 | 0 |

编码帧 ID 示例：

```text
28, 35, 42, 49, 56, 63, 70, 77, 84, 91...
```

每隔约 6～7 个原始摄像头回调发送 1 帧，与 30Hz 回调中抽取 5Hz 一致。

Receiver 日志同时验证 Stride 修复：

```text
I420 export: width=960 height=540 strideY=1024 strideU=512 strideV=512
```

## 4. Receiver 命令

Receiver 继续使用 Stride 修复版：

```bash
docker run -d \
  --name pandia-receiver \
  --network host \
  --gpus all \
  -e NVIDIA_DRIVER_CAPABILITIES=all \
  -v "$HOME/Workspace/Pandia/bin/peerconnection_camera_stridefix:/opt/pandia-bin/peerconnection_camera_stridefix:ro" \
  -v "$HOME/Workspace/Pandia/bin/nvidia-libs:/opt/nvidia-libs:ro" \
  -e LD_LIBRARY_PATH=/opt/nvidia-libs \
  --entrypoint /opt/pandia-bin/peerconnection_camera_stridefix \
  johnson163/pandia_receiver:latest \
  --receiving_only \
  --port 9999 \
  --dump_path /dump
```

## 5. 5FPS MP4 参数

如果使用外部录制脚本，帧率参数应与 Sender 一致：

```bash
python3 /home/cjq/camtest/camera_external_recorder.py \
  --input-dir /home/cjq/camtest/yuvout_final \
  --raw-output /home/cjq/camtest/received_5fps.yuv \
  --mp4-output /home/cjq/camtest/received_5fps.mp4 \
  --width 960 \
  --height 540 \
  --fps 5 \
  --duration 3600 \
  --idle-timeout 5
```

注意：`--fps 5` 只用于 MP4 播放时间轴；YUV 花屏是否正确仍取决于 `--width 960 --height 540` 是否与实际输出一致。
